# Seguimiento a Recomendaciones — Comité Académico

Plataforma de seguimiento a la implementación de las recomendaciones del
Comité Académico de La Universidad en el Campo, dirigidas a instituciones
educativas, universidades aliadas y entidades.

- **Panel de control**: registro de recomendaciones, asignación a uno o
  varios destinatarios (mezclando tipos) y consolidado de cumplimiento.
- **Portal por magic link**: cada destinatario recibe un enlace personal
  (`/portal?token=...`) para reportar avance y cargar evidencias, sin login.

Sitio: https://alianzaeducacionrural.github.io/seguimientorecomendaciones/

Ver [CLAUDE.md](CLAUDE.md) para arquitectura, modelo de datos y comandos.
